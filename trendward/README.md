# Trendward public dashboard v16

Scanner intelligence:
- Free: 4 metrics — Session Move, 5m Liquidity, 25% Model, Price
- Basic: 6 metrics — Free + Price vs VWAP, Distance from Session High
- Pro: 10 metrics — Basic + 10% Model, 50% Model, 15m Liquidity, Spread
- Premium: all currently useful approved scanner fields — Pro metrics plus 5m/15m Dollar Volume, 10/25/50 Model Rank, and First Promotion Time.
- Premium metrics are grouped into Price & Structure, Liquidity, and Model Intelligence.
- Clicking a metric switches the chart to that measurement with its real unit and scale.
- Pro/Premium include a plain-English “Why This Setup?” summary derived only from the public scanner payload.

# Trendward public dashboard v15

Changes:
- Scanner charts are raised/centered and now use real single-snapshot bullet/value charts with labeled axes and units.
- The four Scanner metric boxes are clickable and switch the chart between Session move %, 5m liquidity ×, 25% model /100, and captured price $.
- Free explicitly chooses the top Selected/Promoted setup from its delayed candidate set.
- Current tier badge opens an upgrade-only dropdown: Free -> Basic/Pro/Premium, Basic -> Pro/Premium, Pro -> Premium.
- Upgrade choices open the existing signup-preview modal and identify the target plan.
- Free/Basic watchlists are manual selections from the current Scanner.
- Pro supports manual selection up to 5 or Auto-current up to 5; Premium supports manual selection up to 10 or Auto-current up to 10.
- Manual watch symbols automatically disappear when they leave the current visible Scanner.
- Pro receives an inline Premium upsell when more than 5/current-all access is desired.
- Pro/Premium page help is now a prominent ? button in section headings.
